项目内容：本项目主要以微博公开文本数据为基础，面向舆情分析与用户情感洞察场景，针对短文本噪声多、语义模糊、类别不平衡
等痛点，构建高效情绪识别模型，实现对文本情绪（积极 / 消极 / 中性）的精准分类与趋势分析：
1. 数据采集与预处理：爬取多个热点的评论，完成去重、降噪、分词及特殊字符清洗，构建含 1 万 + 标注样本的情绪数据集；采
用 SMOTE 过采样与类别权重调整，缓解情绪类别分布失衡问题。
2. 特征工程与模型构建：对比 TF-IDF、Word2Vec 及预训练语言模型（BERT-base）的文本表征能力，最终选用中文 BERT 作为
backbone，设计全连接分类头实现三分类情绪识别；引入情感词典（HowNet、NTUSD）增强文本情感特征表达。
3. 模型训练与优化：实现 Focal Loss 损失函数抑制长尾类别影响，采用余弦退火学习率衰减与梯度裁剪策略防止过拟合；通过 5
折交叉验证评估模型性能，对比不同预训练权重与超参数组合，优化模型泛化能力。
4. 应用部署与可视化：将模型封装为 FastAPI 接口，支持批量文本情绪识别；开发简易可视化 Dashboard，展示情绪分布热力图
与时间趋势，实现舆情事件情绪倾向的实时监控。
项目成果：模型在测试集上情绪分类准确率达 89.2%，F1 值提升至 88.5%，较基线 TextCNN 模型准确率提升 12.3%；API 单条文
本处理延迟 < 50ms，能够在模拟舆情监控场景中有效识别热点事件情绪走向。
